# demo-files: 테스트·시연 데이터용 원본 파일

DB 테스트 데이터(`db/03~07`)의 파일 행이 가리키는 원본이다. `db/load_demo_files.sh`(만들 예정)가 이 파일을 업로드 폴더에 사업별 저장 이름으로 복사한다. 내용은 모두 견본이며 실제 효력이 없다.

| 폴더 | 파일 | 쓰는 곳 |
|---|---|---|
| `proposal/` | 통합본 2(1차·최종), 파트 3(PPTX 2·PDF 1), 제안요약서 2 | 제안서 관리 (FL030 · FL020 · FL040) |
| `rfp/` | 제안요청서 A(요구사항 16개), B(18개) | 공고 첨부 RFP (FL010). 요구사항 추출 형식(총괄표·목록표)에 맞춤 |
| `docs/` | 사업자등록증 · 법인등기부등본 · 재무제표 · 입찰참가신청서(PDF), 청렴서약서 · 보안확약서(DOCX), 투입인력현황(XLSX) | 제출서류 (FL050) |
| `evaluation/` | 평가표 샘플 (앱이 읽는 양식: `평가항목` · `배점기준` · `평가위원N`) | 평가표 (FL070). 사업별 평가표는 이 양식으로 만든다 |
| `refs/font` | Noto Sans KR · Noto Serif KR 부분 글꼴(완성형 2,350자, OFL) | 참고자료 폰트 |
| `refs/image` | 조직도.png · 시스템구성도.png · 표지배경.jpg | 참고자료 이미지 |
| `refs/doc` | 제안서작성가이드.pdf · 회사소개서.docx · 수행실적목록.pdf | 참고자료 문서 |
| `refs/etc` | 아이콘모음.zip · 표지템플릿.svg | 참고자료 기타 |
| `demo-upload/` | 시연 때 직접 올릴 파트 2 · 통합본 1 | 시연용 (미리 넣지 않음) |

시연 공고의 실제 RFP는 사용자가 따로 준비한다.
